fDA：未注释基因组中结构域感知的靶向直系同源搜索及β-内酰胺基因发现

无需预先注释，直接从未注释基因组中找直系同源物，并发现弹尾虫可能是被忽视的β-内酰胺抗生素生产者。

Targeted ortholog search in unannotated genome assemblies with fDOG-Assembly.
Nucleic acids research · 2026 Sep 22
Hannah Muelbaier, Freya Arthen, Vinh Tran, Ina Schaefer, Miklós Bálint, Ingo Ebersberger

入选理由：fDA工具无需预先注释即可在未注释基因组中做结构域感知的直系同源搜索，并意外发现弹尾虫中广泛存在β-内酰胺生物合成基因，提示动物可能是被忽视的抗生素生产者，既实用又有新方向启发。

研究背景

公共数据库中真核基因组组装数量快速增长，但只有约16%的组装带有基因注释；全基因组注释仍是大基因组真核生物的瓶颈，导致大量组装无法用于进化和功能基因组学分析。

现有的靶向直系同源搜索工具（如 fDOG、KofamKOALA）依赖预先注释的蛋白质组，基因漏注释会在系统发育谱中形成假性丢失信号。少数可在未注释基因组中工作的工具（如 BUSCO、Compleasm）只能处理通用单拷贝基因集，不支持用户自定义基因，且不评估蛋白质特征结构差异。

因此，需要一种能直接从未注释基因组中搜索任意目标基因直系同源物、同时提供特征结构相似性评估的工具。

核心发现

fDA 在基准测试场景1中，用954个 metazoa_odb10 单拷贝基因在10个后生动物基因组中搜索，与 BUSCO、Compleasm 的直系同源分配高度一致；约7022个直系同源对被所有8种搜索策略共同识别，另有1170个被至少6种策略识别（见图 3A）。精度与基于蛋白质组的13种工具相当，灵敏度略低。

在214个“仅在一个物种中缺失”的 BUSCO 基因谱系缺口案例中，基于组装的方法能填充其中超过80个缺口；没有 UniProt ID 对应的新预测直系同源物填充缺口的比例（11.5%–24.75%）高于已有 UniProt ID 的（2.4%–6.7%），说明 fDA 确实能找回注释遗漏的基因，而不是主要产生假阳性。

在场景2中，用5000个人类蛋白在褐家鼠 (Rattus norvegicus) 和星状海葵 (Nematostella vectensis) 的未注释基因组中搜索，fDA-MP 恢复共识直系同源对的94.6%，fDA-tbME 为90.6%；对1:1直系同源组最高可恢复97%的组，但对 n:n 共直系同源组恢复率明显下降。

案例研究中，fDA 筛选了176个土壤无脊椎动物基因组中β-内酰胺合成相关基因，发现152个物种至少含有一个相关酶直系同源物。UMAP 聚类显示，聚类4和6主要由弹尾虫组成，部分物种（如聚类6中的 Onychiurinae 成员）拥有除 cmcH 外完整的 Cephamycin C 生物合成基因集（见图 5）。经过 DIAMOND 分类学分配和邻近基因分析，排除了大多数微生物污染可能，表明这些基因确实编码于动物自身基因组。

方法亮点

fDA 的流程包括输入处理、候选区域识别、基因预测和直系同源验证四个步骤（见图 1）。核心直系同源组由 fDOG 预先计算，fDA 训练 pHMM、生成一致序列，若使用 Augustus 则额外构建 block profile。

候选区域识别提供 tblastn 或 MiniProt 两种策略：tblastn 用一致序列搜索基因组，必要时合并相邻命中；MiniProt 同时用一致序列和核心组所有蛋白搜索，保留最佳比对区域。基因预测可在 Augustus、MetaEuk 或 MiniProt 快速模式间切换，Augustus 可结合 block profile 提升预测质量。

直系同源验证采用反向 BLASTP 对参考物种蛋白质组搜索，结合最佳命中和 Kimura 距离判据处理候选和共直系同源关系；最后用 FAS 计算预测直系同源物与种子蛋白的特征结构相似性，输出序列、注释、FAS 分数和系统发育谱。基准测试利用 QfO benchmark service 评估 EC/GO 语义相似度和 TreeFam 一致性，并与 BUSCO、Compleasm 及13种蛋白质组工具比较。

图 1｜fDA 四步工作流程

图例：fDOG-Assembly 的工作流程。(A) fDA 从一个预先计算的核心直系同源组开始，该组带有相应氨基酸序列的多序列比对（MSA），以及用该 MSA 训练的谱隐马尔可夫模型（pHMM）。从 pHMM 计算一致序列，并用 MSA 生成 block profile。(B) fDA 提供两种互补策略来识别可能含有直系同源物的候选基因组区域。一种策略以一致序列为查询进行 tblastn 搜索。另一种策略使用 MiniProt，以一致序列和核心直系同源组中的所有蛋白质作为查询搜索目标基因组。(C) 来自 (B) 的每个候选区域作为基因预测的输入。fDA 提供三种基因预测选项：Augustus 结合预先计算的 block profile，MetaEuk 结合参考数据库，或在快速模式下使用 MiniProt。(D) 为验证来自 (C) 的直系同源候选基因，将预测基因的氨基酸序列作为查询，对用户指定参考物种的蛋白质组进行反向 BLASTP 搜索。如果保留两个或更多候选直系同源物，则仅当它们彼此之间的成对距离小于各自到参考蛋白的距离时，才将它们接受为共直系同源物。否则，选择与参考蛋白距离较小的候选者。直系同源搜索最后通过评估所鉴定直系同源物与种子基因之间的成对特征结构相似性来完成。

图解：这张图回答的是 fDA 如何在不依赖预先注释的情况下，从未注释基因组中完成靶向直系同源搜索。图 A 说明输入处理：用户提供核心直系同源组和 MSA，fDA 训练 pHMM、生成一致序列和 block profile。图 B 展示候选区域识别的两种策略：tblastn 一致序列搜索或 MiniProt 多查询搜索。图 C 展示基因预测的三种选项：Augustus 加 block profile、MetaEuk 加参考数据库或 MiniProt 快速模式。图 D 说明直系同源验证：预测蛋白对参考物种蛋白组做反向 BLASTP，根据最佳命中或 Kimura 距离验证候选者，并处理共直系同源关系；最后用 FAS 比较特征结构。该流程使 fDA 能在目标区域进行局部基因预测，绕过全基因组注释，同时提供基因结构质量评估。

为什么值得读

对从事比较基因组学或系统发育谱分析的研究者来说，fDA 意味着可以绕过耗时的全基因组注释，直接利用海量未注释组装扩大分类单元采样，同时通过 FAS 分数获得基因结构完整性的质量控制。

对合成生物学和天然产物挖掘而言，fDA 的案例展示了一种在未注释动物基因组中发现次生代谢基因簇的路径：弹尾虫中近乎完整的 Cephamycin C 途径提示动物可能是未被充分认识的抗生素生产者，为寻找新型抗菌化合物或抗性基因提供了新方向。

此外，fDA 的模块化设计（多种候选区域识别与基因预测组合）允许用户在速度、灵敏度和基因模型准确度之间权衡，适合不同规模的分析；其输出可直接导入 PhyloProfile 进行交互式探索。

局限与疑问

本研究基准主要基于后生动物基因组，且核心直系同源组依赖 fDOG 预先计算；参考物种选择会影响搜索灵敏度和特异性，对进化距离极远的类群尚未充分测试。

fDA 的灵敏度总体略低于基于完整蛋白质组的工具，特别是 n:n 共直系同源组的恢复率显著降低；使用 MiniProt 快速模式时，基因预测倾向于截短，会降低 FAS_F 分数，若下游需要完整基因结构应优先选择 Augustus。

案例研究中，许多基因组组装高度碎片化（N50 常低于20 kb），BUSCO 完整性也较低，因此无法区分基因缺失与组装缺口；分类学分配对某些基因的起源仍不确定，β-内酰胺合成酶的功能活性和产物结构还需实验验证。此外，fDA 只检测与已知种子基因同源的序列，无法识别全新或高度分化的同源基因。
