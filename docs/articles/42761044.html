大语言模型作为不确定性校准的实验发现优化器

GOLLuM 用 LLM 过度自信当训练信号，10 个低分实验起步，少 40% 实验即达传统 BO。

Large language models as uncertainty-calibrated optimizers for experimental discovery.
Nature machine intelligence · 2026
Bojana Ranković, Ryan-Rhys Griffiths, Philippe Schwaller

入选理由：GOLLuM将LLM的过度自信转化为贝叶斯优化信号，仅从少量低性能实验出发即可高效指导反应优化与分子设计，直接契合酶工程和合成生物学实验迭代需求，方法巧思且开放全文。

研究背景

AI 现在可以快速生成数百万候选药物、材料结构或化学反应，但真正的瓶颈在于决定下一个应该测试哪个候选。实验优化长期依赖贝叶斯优化（Bayesian optimization, BO），它通过高斯过程（Gaussian process, GP）等代理模型提供预测和不确定性，以平衡探索与利用。然而，BO 通常需要领域特定的特征表示，例如化学反应指纹或量子化学描述符，这些表示很少能跨域迁移，导致每个新领域都要从头开始。

大语言模型（large language models, LLMs）具备丰富的跨领域先验知识，可以通过自然语言接口工作，但它们在实验优化中的直接应用受到幻觉和过度自信的严重制约。LLM 会输出听起来自信但事实错误的内容，这在实验室中可能浪费资源、延误进度甚至危及安全。因此，如何将 LLM 的广度知识与 BO 的可靠性原则结合起来，成为亟待解决的问题。

核心发现

GOLLuM（Gaussian Process Optimized LLMs）在 23 个跨领域任务上平均排名第一，这些任务涵盖有机合成、材料科学、过程化学和分子设计。从 10 个低绩效实验冷启动，在 50 次实验预算下，GOLLuM 达到 36.3% 的 top-5% 覆盖率，超过 BoChemian（26.5%）、LAPEFT（12.1%）以及使用领域定制描述符的传统 GP BO（29.7%）。在过程化学中提升最大，相对改进 90%；在有机化学中提升 28%；在分子性质优化中保持竞争力。GOLLuM 还展现出更高的样本效率：与传统 BO 达到相同最终性能所需实验数中位数减少 41%（见图 2）。

在 Buchwald–Hartwig 交叉偶联反应基准上，GOLLuM 将高产条件发现率从固定 LLM 嵌入的 24% 提升到 43%，相对改进 79%，超过专家量子化学描述符和 SOTA LLM。对 T5、Qwen-7B、ModernBERT 和 OpenAI 嵌入等不同架构，通过 GP 边际似然微调均带来大幅提升。诊断分析发现，优化性能与表征的几何平滑度（学习到的 GP 长度尺度 ℓ 与平均成对嵌入距离 d̄ 之比）强相关（r=0.92），远高于与回归 R² 的相关性，说明微调的关键在于重组嵌入空间，而非单纯提高预测精度（见图 3）。

机制上，GP 边际似然优化充当了隐式对比学习：它使结果相似的实验在嵌入空间中靠近，结果不同的实验远离，从而将 LLM 潜在空间组织成高绩效和低绩效分离的区域。在 Buchwald–Hartwig 任务中，这种组织逐渐涌现，到第 50 次迭代时，碘代物高产实验与氯代物低产实验清晰分离，形成化学可解释的簇（见图 4）。相反，直接提示 SOTA LLM 作为优化器的失败率高达 10%–80%，大量建议无效、重复或无法解析，优化性能也远低于概率框架（见图 5）。

方法亮点

GOLLuM 将实验条件通过标准化模板转化为自然语言描述，再经 LLM 编码为连续嵌入，作为 GP 的输入。其核心创新在于联合优化 LLM 参数（通过 LoRA 和/或线性投影层）与 GP 超参数，共同最大化 GP 边际似然，而不是先做回归再事后添加不确定性估计。这相当于让 GP 的概率目标直接塑造 LLM 的表征，无需显式对比损失。

该方法支持参数高效微调：即便只有 10 个初始数据点，也能通过梯度反向传播调整大型预训练 LLM 的 LoRA 适配器，避免灾难性遗忘。对于无法获取权重的闭源 LLM，可利用线性投影层（PLLM 变体）在固定嵌入上学习任务特定变换。整个流程可处理混合变量和连续变量，统一使用自然语言接口，无需为每个新任务设计专用内核或特征。

为什么值得读

对合成生物学和蛋白工程研究者来说，GOLLuM 提供了一种低门槛、高样本效率且可解释的实验优化范式。合成生物学中的组合优化（如启动子、RBS、诱导条件、培养基配方等）通常涉及混合变量，传统特征工程繁琐且难以迁移。GOLLuM 允许直接用自然语言描述每个实验条件，在少量初始实验后就能指导下一轮迭代，并且其学到的嵌入空间能可视化揭示哪些因素驱动高绩效，帮助研究者理解设计空间结构。

方法论上，这项工作展示了将基础模型与概率模型深度融合的力量：不确定性不是 LLM 的缺陷，而是可以转化为训练信号的资源。这种思路可能启发其他高不确定性、高成本领域（如定向进化、代谢工程、自驱动实验室）开发更可靠的 AI 助手。

局限与疑问

GP 的标准实现存在立方级计算复杂度，当实验数量达到数千时可能难以扩展，需要引入可扩展 GP 近似。文本接口在缺乏清晰语言结构的高维数据（如蛋白质构象、晶体结构）上可能效果下降，未来可能需要混合专用编码器。

此外，论文中的评估主要基于模拟基准和已枚举的化学反应数据集，真实湿实验验证有限。冷启动需要 10 个低绩效但有效的实验，若初始实验全部完全失败可能影响学习信号。可解释性可视化提供的化学或生物解释是否反映真实因果机制，还是事后归纳，也值得进一步追问。基准选择可能偏向文本描述友好的任务，更广泛的生物实验场景仍有待检验。
